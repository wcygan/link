# Product Requirements Document 

A service that:

1. Shortens URLs
2. Previews URLs
3. Generates QR codes

## URL Shortening

Input:

- URL
- Custom short code
- Expiration

Output:

- Short URL

## URL Preview

Input:

- URL

Output:

- URL Preview:
- Title
- Description
- Timestamp of when the preview was generated

## QR Code

Input:

- URL

Output:

- QR Code
- Timestamp of when the QR code was generated
